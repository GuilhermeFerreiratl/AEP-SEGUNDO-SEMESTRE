# Sistema PSE - Controle de Alunos com TEA e Restrição Alimentar

Sistema em Linguagem C para controle de alunos do Programa Saúde na Escola (PSE).
Controla quem tem TEA, quem tem restrição alimentar e quem precisa de acompanhamento.

## Objetivo
Ajudar a secretaria e a nutricionista a saberem rapidamente:
- Quem tem TEA
- Quem tem restrição alimentar e qual alimento
- Quem precisa de acompanhante mas ainda não tem
- Relatório por escola e por cidade para a cantina
